# Sumitra Modal – Personal Portfolio Website

## About the Project
This is a personal portfolio website created by Sumitra Modal, a BCA (Bachelor of Computer Applications) student. It showcases my skills, projects, and contact information.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Google Fonts

## Features
- Modern and responsive design
- About Me section
- Skills section
- Project showcase
- Contact section
- Dark theme with purple accents

## Projects
- **Temperature Converter:** Converts temperature between Celsius, Fahrenheit, and Kelvin.
- **Personal Portfolio:** A website showcasing my skills and projects.

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
