# Samsung Galaxy Landing Page 📱

## 📌 About the Project

This project is a modern, responsive landing page inspired by Samsung Galaxy smartphones. It features a premium dark theme, elegant typography, product highlights, and links to Samsung's official website and social media accounts.

This is a student project created for the OIBSIP Web Development Internship.

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling, animations, and responsive layout
- **Google Fonts** – Poppins typography

## ✨ Features

- Sticky navigation bar with multiple links
- Hero section with headline and call-to-action buttons
- Smartphone product showcase
- Features section highlighting camera, performance, battery, and S Pen
- About section with product information
- Customer testimonial section with sample reviews
- Call-to-action section
- Footer with official Samsung website and social media links
- Hover effects and smooth scrolling
- Responsive layout for desktop, tablet, and mobile devices
- Consistent black, white, and blue colour palette
- No JavaScript required

## 🚀 How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Make sure `index.html` and `style.css` are in the same folder.
4. Open `index.html` in your web browser.
5. Explore the navigation, product sections, and external links.

## 🎨 Design Highlights

- Premium dark background
- Blue accent colours
- Modern typography using Google Fonts
- Responsive CSS Grid and Flexbox layouts
- Rounded cards and subtle hover animations
- Clean spacing and readable content

## 🎯 Objective

The objective of this project is to practise HTML5 and CSS3 by creating a visually appealing, responsive product landing page with a consistent design and functional navigation links.
